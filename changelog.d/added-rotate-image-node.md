- Rotate Image node turns an image 90° clockwise, 180°, 90° counter-clockwise, or by a custom angle,
  each with an icon in the Rotation list. Quarter turns are lossless. A custom angle grows the canvas
  by default so no corners are cut off, and fills the corners with a Background Color, transparent by
  default.
  [#906](https://github.com/griptape-ai/griptape-nodes-library-standard/issues/906)
