- `Questions (JEV)` asks several questions about the same text and images in one JEV call, so the
  context is billed once. Add questions with `+ Yes/No`, `+ Pick One` or `+ Rate`, or connect
  `Yes/No Question (JEV)`, `Pick One Question (JEV)` or `Rate Question (JEV)` nodes. `answers` holds
  each answer under the question's `Name`; `details` adds probabilities and confidence.
  [#743](https://github.com/griptape-ai/griptape-nodes-library-standard/issues/743)
