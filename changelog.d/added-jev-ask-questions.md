- `Questions (JEV)` with `Yes/No Question (JEV)`, `Pick One Question (JEV)` and
  `Rate Question (JEV)` nodes. Ask several questions about the same text and images in one JEV call,
  so the context is billed once. Click `+ Yes/No`, `+ Pick One` or `+ Rate` on `Questions (JEV)`
  to add a question node already connected, or connect your own. `answers` holds each answer under
  the question's `Name`, and `details` holds probabilities and confidence.
  https://github.com/griptape-ai/griptape-nodes-library-standard/issues/743
