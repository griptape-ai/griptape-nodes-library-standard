description: Generates one to four videos, with audio, from a prompt and optional images using Google Veo 3.1.

## When to use it

You want a short video from a prompt or a starting image. Audio is generated by default and can be turned off with `generate_audio`. You can generate up to four variations in one run. Use start and end frames or reference images to steer the clip.

## What it needs

- A Griptape Nodes license or a Griptape Cloud API key (`GT_CLOUD_API_KEY`). To use your own Google Cloud service account JSON (`GOOGLE_SERVICE_ACCOUNT_JSON`) instead, set **Credentials Provider** to **Customer**.
- The node waits for the result. `timeout` sets how long, 600 seconds by default, or 0 for no limit. If a run times out, the **Refresh** button on the node fetches the result later.

## Parameters

### model_id

| Model | `start_frame` | `last_frame` | `reference_images` |
|-------|---------------|--------------|--------------------|
| `veo-3.1-generate-001` (default) | Yes | Yes | Yes |
| `veo-3.1-fast-generate-001` | Yes | Yes | No |

Saved workflows that used Veo 3.0 are switched to the matching 3.1 model.

### reference_images and reference_type

Only for `veo-3.1-generate-001`. `asset` keeps objects or characters from the images and accepts up to 3. `style` keeps the artistic style and uses 1. Extra images are ignored.

Connecting reference images forces `duration_seconds` to 8. A run with reference images and another duration stops with an error.

### duration_seconds

4, 6 or 8 seconds.

### resolution

1080p only supports 8 seconds, so pick 8 seconds with it. The node only logs a warning if you pick another duration.

### person_generation

`allow_all`, `allow_adult` (default) or `dont_allow`. Controls whether the model generates people.

### sample_count

1 to 4. Each video is saved to its own output: `video_url`, then `video_url_2` to `video_url_4`. Only the outputs that were produced are shown.

### seed

Use `randomize_seed` to get a new seed on each run.

## Edge cases

- If one video cannot be saved, its slot stays empty and the others keep their places.
- Videos filtered by Google's safety checks are logged.
