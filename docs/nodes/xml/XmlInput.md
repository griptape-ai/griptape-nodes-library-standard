## When to use it

You have XML and want to send it into a workflow. Type or paste it into the `xml` field. The same value is available as an output to connect to nodes such as [XML Extract Value](XmlExtractValue.md) or [XML Replace](XmlReplace.md).

The node does not check or change the text.
