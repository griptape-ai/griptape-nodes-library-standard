---
description: Outputs a true or false value you set on the node.
when_to_use: Use it for a switch in a workflow, such as turning an optional step on or off.
---

## When to use it

You want one boolean that you set by hand and send to other nodes, for example a flag that enables a denoise pass.

## Parameters

### bool

The value. It defaults to false. The node outputs this same value on its `bool` output.
