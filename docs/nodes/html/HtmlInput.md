description: Holds a block of HTML that you type or paste, and passes it on as an output.
when_to_use: Use it when you want to write HTML by hand and feed it to other nodes.
---

## When to use it

You have HTML and want to send it into a workflow. Type or paste it into the `html` field. The same value is available as an output to connect to nodes such as [HTML Extract Value](HtmlExtractValue.md).

The node does not check or change the text.
