description: Shows YAML data in a formatted viewer on the node.
when_to_use: Use it when you want to see the YAML coming out of another node.
---

## When to use it

Connect YAML from another node, such as [YAML Replace](YamlReplace.md), to read it on the canvas while you build. The node has one `yaml` input and no outputs, and it does not change the data.
