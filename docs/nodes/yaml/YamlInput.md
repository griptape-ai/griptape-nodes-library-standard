## When to use it

You have YAML, such as a config or a list of settings, and want to send it into a workflow. Type or paste it into the `yaml` field. The same value is available as an output to connect to other nodes, for example [YAML Extract Value](YamlExtractValue.md) or [YAML Replace](YamlReplace.md).

The node does not check or change the text.
