---
description: Shows text on the node, rendered as markdown, and passes it through unchanged.
when_to_use: Use it when the text you want to read has markdown formatting, such as headings, lists or bold, and you want to see it formatted.
---

## When to use it

An Agent or a text node returns markdown, and reading the raw `#` and `*` characters is hard. Connect the text here to see it rendered. It works like [DisplayText](DisplayText.md) and only changes how the text is shown.

## Parameters

### text

The text to show. Type it in or connect it. The same text is available on the output, so you can keep passing it to other nodes. The text is not changed.
