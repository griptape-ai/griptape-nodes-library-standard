---
description: Combines a list of images into one multi-page PDF, one image per page.
when_to_use: Use it when you want to deliver or review a set of images as a single PDF, such as a contact sheet or storyboard.
---

## When to use it

Connect your images, in order, and get one PDF with each image on its own page. The page order follows the order of the list.

## Parameters

### images

Add images one by one or connect a list. At least one image is required.

Transparent areas are filled with white. Other image modes are converted to RGB.

### output

The saved PDF, named by `output_file`. The default name is `output.pdf`.
