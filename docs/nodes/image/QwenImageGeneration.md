## When to use it

Write a prompt, pick one of five sizes and get one image back. To change an existing image, use [Qwen Image Edit](QwenImageEdit.md).

## What it needs

- A Griptape Nodes license or a Griptape Cloud API key (`GT_CLOUD_API_KEY`). To use your own Alibaba Cloud Model Studio key (`DASHSCOPE_API_KEY`) instead, set **API Key Provider** to **Customer**.
- The node waits for the result. `timeout` sets how long, 600 seconds by default, or 0 for no limit. If a run times out, the **Refresh** button on the node fetches the result later.
- Workflows saved with the older Qwen Image or Qwen Image Plus models are migrated to `qwen-image-3.0`.

## Parameters

### size

Sizes are fixed so each matches a common aspect ratio.

| Size | Ratio |
| --- | --- |
| 1328*1328 | 1:1 |
| 1664*928 | 16:9 |
| 1472*1140 | 4:3 |
| 1140*1472 | 3:4 |
| 928*1664 | 9:16 |

### seed

Use the same seed with the same inputs to repeat a result. Turn on `randomize_seed` to get a new seed each run.

### prompt_extend

Lets the service rewrite your prompt to improve quality. It adds 3 to 4 seconds. Off by default.

### watermark

Adds a "Generated by Qwen-Image" mark in the lower-right corner. Off by default.
