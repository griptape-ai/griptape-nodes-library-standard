---
description: Converts an image to grayscale.
when_to_use: Use it when you need a black and white version of an image, for example before a mask or a stylized look.
---

## When to use it

Removes all color from an image and keeps the brightness. The node does this by setting the image's saturation to zero.

## Parameters

### output_format

`auto` saves the result in the same format as the input.

### quality

Only affects lossy formats such as JPEG.
