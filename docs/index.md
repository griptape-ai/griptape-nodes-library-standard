---
title: "Standard Library"
---

The Standard Library (`Griptape Nodes Library`) holds the default nodes for Griptape Nodes. Each node has a page that explains what it is for, how its parameters behave, and what it needs to run, such as a Griptape Cloud key or a provider API key.

The pages are grouped by node type under `nodes/`: agents, audio, image, video, three_d, text, lists, dict, json, xml, yaml, html, files, number, execution, variables, rules, tools and others.
